# HEARTCODE

> She asked for my heart. So I coded it.

A single-file interactive page: hold to start the pulse, watch a heart form out of particles, then send a personalized link.

## Personalize

Add query params to the URL:

```
?to=Emma&msg=You%20already%20had%20it.&from=Alex
```

Or use the **personalize** panel in the bottom-left corner.

## Run locally

It's just `index.html` — open it in a browser, or:

```
npx serve .
```
